# Powy iPad、个人外观与热量显示设计

## 目标

1. 饮食记录保存后，以大号统计卡明确展示每日目标减去已摄入热量后的“今日剩余”。
2. 用户可从相册设置头像和壁纸，也可分别恢复默认。
3. iPad 横屏和竖屏均填满可用页面，不再被 440px 手机宽度限制。
4. 使用用户提供的 Power 图片制作 Powy 网站与 PWA 图标。

## 布局

- 手机小于 768px：保持现有单栏漫画布局。
- iPad 竖屏从 768px 起：App、页头、导航铺满屏幕；内容限制到舒适阅读宽度，多组卡片可两列排列。
- iPad 横屏从 1024px 起：生活页的输入/配置卡与当天时间线/结果卡左右并排。
- 自定义壁纸覆盖整个 App 画布，主体内容保留半透明暗色底和不透明纸张卡片以维持可读性。

## 个人外观存储

- 头像与壁纸通过隐藏的 `accept="image/*"` 文件输入从相册选择。
- 浏览器用 Canvas 纠正方向并压缩为 WebP：头像最长边 512px；壁纸最长边 2048px。
- 压缩结果存入独立 IndexedDB `powy-profile-v1`，不占用任务/生活数据的 localStorage 配额。
- 页面启动时异步加载；URL 用 `URL.createObjectURL`，替换或恢复默认时撤销旧 URL。
- 文件无法解码、超过处理边界或 IndexedDB 写入失败时显示双语错误，不改变现有图片。
- 当前版本按设备保存；账号后端未配置前不声称跨设备同步。

## 热量呈现

- 保留“每日热量目标”输入框作为设置，不把它伪装成动态余额。
- 当天摘要显示三张统计：剩余、已摄入、目标。
- 剩余值为 `target - consumed`；例如目标 2000、鸡蛋 70，显示剩余 1930。
- 超过目标时保留负数并使用警示色，不阻止继续记录。

## 验收

- iPad 768×1024 与 1366×1024 不出现大面积外部黑边，App 宽度为视口宽度。
- 横屏生活页形成双列，手机仍为单列。
- 头像和壁纸可上传、刷新后恢复、分别重置。
- Logo 的 HTML favicon、apple-touch-icon、manifest 三种图标使用新 Power 图。
- 自动测试、媒体、语法、Service Worker 和线上文件检查通过。
